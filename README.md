# 🚀 Space Defender


A 2D space action game built with HTML, CSS, and JavaScript. Control a spaceship, avoid meteors, defeat enemies, and survive through challenging levels.


## 🎮 Features

- 🚀 Control a spaceship
- ☄️ Avoid falling meteors
- 🔫 Shoot meteors and enemies
- ❤️ Lives system
- ⭐ Score and high-score tracking
- 🛡️ Power-ups
- 👾 Boss battles
- 🎯 Adventure and Infinity game modes
- 📱 Designed with responsive gameplay in mind


## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages


## 🎮 How to Play

1. Start the game and choose a game mode.
2. Move the spaceship to avoid incoming meteors and enemy attacks.
3. Shoot meteors and enemies to earn points.
4. Collect power-ups when they appear.
5. In Adventure mode, progress through increasingly difficult levels.
6. In Infinity mode, survive for as long as possible.
7. Defeat bosses when you reach boss levels.
